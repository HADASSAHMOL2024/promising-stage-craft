# Promising Stage Craft website

A responsive static website built with HTML, CSS and JavaScript.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Enquiry form
The enquiry form opens WhatsApp with the visitor's details pre-filled for +91 99464 66737. It does not store submissions on a server.

## Replace sample photographs
Update the image URLs in `index.html` with your own photographs when ready.

## Publish online
This static site can be hosted using GitHub Pages, Netlify, or a regular web hosting provider. A custom domain can be connected after hosting is set up.

## Important
The website currently uses sample online photographs and a text-based placeholder logo. Replace these with the approved business logo and real event photos before final public launch.
